# 오손도손
**따뜻한 이웃, 행복한 우리**

## 1. 프로젝트 개요
**오손도손**은 IoT와 AI 기술을 결합해 층간 소음 문제를 부드럽게 해결하는 커뮤니케이션 솔루션입니다.  
IoT 센서를 통해 소음 데이터를 객관적으로 수집하고, Gemini API 기반의 AI 메시지 순화 기능을 활용하여  
이웃 간의 갈등을 최소화하며 **상호 존중하는 주거 문화를 조성**하는 것을 목표로 합니다.

---

## 2. 핵심 기능

### 📡 소음 데이터 시각화
- ESP32 기반 IoT 센서가 실시간 소음 데이터를 수집합니다.  
- 수집된 소음 데이터(dB)를 **대시보드**에서 실시간으로 확인할 수 있습니다.  
- 사용자는 자신의 생활 소음을 객관적으로 파악하여 스스로 생활 습관을 개선할 수 있습니다.

### 🤖 AI 기반 메시지 순화
- 사용자가 입력한 메시지를 규칙 기반 함수를 통해 파악하고 비속어가 포함된 메시지이면 **Gemini API**에게 전달합니다. 
- 공격적이거나 불편하게 들릴 수 있는 표현을 **부드럽고 공손한 문장**으로 변환합니다.  
- 예시)  
  - 입력: `"조용히 좀 해. 시끄러워 죽겠네!"`  
  - AI 추천: `"늦은 시간에 소리가 조금 크게 들리는데 괜찮으신가요?"`

### 🏠 '오손'과 '도손' 소통 채널
- '오손(우리집)'과 '도손(이웃집)'이라는 친근한 명칭의 소통 채널을 제공합니다.  
- AI가 **감정을 배제한 메시지 옵션**을 추천하여 불필요한 감정 소모를 줄이고 원만한 대화를 돕습니다.  

---

## 3. 기대 효과

### 💰 경제적 효과
- 층간 소음 분쟁으로 인한 소송/법률 자문 비용 등 **사회적 비용 절감**  
- 거주민 만족도 향상 → **부동산 가치 상승**  
- IoT 기기 및 AI 기반 커뮤니케이션 서비스 **신규 시장 창출**

### 🤝 사회적 효과
- 이웃 간의 불신과 갈등을 최소화  
- 성숙한 시민 의식을 바탕으로 **상호 배려 문화 형성**  
- 공동체 신뢰 회복에 기여  

### 🌱 환경적 효과
- 불필요한 소음 매트·흡음재 사용 감소 → **자원 절약**  
- 향후 에너지 최적화/주거 환경 개선으로 확장 가능  

---

## 4. 기술 스택 및 구조

- **하드웨어:** ESP32 보드 기반 IoT 소음 센서 모듈  
- **데이터베이스:** Firebase Firestore (실시간 데이터 저장/전송)  
- **AI 서비스:** Gemini API (메시지 순화 및 추천)  
- **백엔드:** Firebase Functions (간단한 로직 처리)  
- **프론트엔드:** 웹 애플리케이션 (React) → 소음 데이터 시각화 & AI 메시지 추천 UI 제공  

---

## 5. 향후 발전 방향
- 홈네트워크/인터폰 업체와의 연계를 통한 아파트 단지 공급  
- 맞춤형 알림/패턴 분석 기능 고도화  
- 커뮤니티 단위의 **스마트 공동체 플랫폼**으로 확장
